2. ShaderReflectionIR 内存模型

根对象

struct ShaderReflectionIR
{
    uint32 Schema = 2;
    StringAnsi PipelineLayoutFingerprint;
    uint32 RootBlockId;
    Array<ShaderTypeRecord> Types;
    Array<ShaderParameterBlockRecord> ParameterBlocks;
};

struct ShaderParameterBlockRecord
{
    uint32 Id;
    StringAnsi Name; // 根块为空；子块使用父成员局部名称。
    uint32 ElementTypeId;
    uint32 UniformByteSize;
    Optional<ShaderDescriptorRange> DefaultUniformBuffer;
    Array<ShaderRangeBinding> RangeBindings;
};
  • 每个完整 ProgramId × TargetKey × Variant 只有一份 IR，全部 Stage 共享。
  • 只有一个 RootBlockId，没有 EntryPoint block；入口只允许 varying/system-value 参数。
  • Types 是可去重的逻辑类型图；ParameterBlocks 是具体出现位置，不因元素类型相同而合并。
  • 所有 ID 都是 Layout 局部、从 0 连续分配的 uint32；运行时直接用数组索引，不构建稀疏 Map。

Type Record

ShaderTypeRecord
  Common:

成员偏移永远相对于直接父类型。运行时沿 ShaderVar 路径累加普通字节偏移、resource range 偏移和 resource index；Builder 不为每个根路径复制同一 Struct。

逻辑 Range 与物理 Mapping

struct ShaderResourceRange
{
    ShaderLogicalResourceKind ResourceKind;
    uint32 Count;
    uint32 BaseIndex;
    Optional<ShaderInternalRole> InternalRole;
    Optional<uint32> OwnerRangeOffset;
};

struct ShaderRangeBinding
{
    uint32 RangeIndex;
    ShaderRangeFlavor Flavor; // Simple / ConstantBuffer / ParameterBlock
    Array<ShaderDescriptorRange> DescriptorRanges;
    Optional<uint32> SubBlockId;
};

struct ShaderDescriptorRange
{
    ShaderDescriptorRole Role;
    uint32 Set;
    uint32 Binding;
    uint32 ArrayElementBase;
    uint32 LogicalElementStride;
    ShaderDescriptorType DescriptorType;
    uint32 DescriptorCount;
    ShaderStageMask StageMask;
    ShaderDescriptorFlags Flags;
};
  • 一个逻辑 range 可映射 1～N 个物理 descriptor range；组合资源、counter 等不得被压成一对一模型。
  • Simple 必须有 descriptor mapping、没有 SubBlock；块 flavor 必须有一个 SubBlock、没有 descriptor mapping。
  • defaultUniformBuffer 与普通 descriptor 使用相同物理字段，但 Role 固定为 uniformData。
  • set/binding 是当前 Target 下相对 Program 根的绝对坐标，不保存 Slang 子块局部坐标。
  • OwnerRangeOffset 保存同一 Type Record 内主 range 的绝对局部索引，不是 counter range 到主 range 的有符号差值；非辅助 range 必须为 null。
  • Resource.AuxiliaryRanges[].RangeOffset 是从该 Resource 主 range 到辅助 range 的正向相对 range 偏移；运行时使用 accumulatedMainRange + RangeOffset。它与辅助 range 上的绝对局部 OwnerRangeOffset 语义不同。
  • ConstantBuffer/ParameterBlock Type Record 自身各有一条 count 为 1 的逻辑容器 range；具体子块的 RangeBindings 则对应其 ElementTypeId 的内容 ranges，二者不能混用。
  • Schema 2 的 simple mapping 固定 ArrayElementBase = 0、LogicalElementStride = 1、DescriptorCount = logical range.Count。反射到非恒等映射时 Builder 必须失败。

3. SlangReflectionBuilder 算法

输入与入口

bool SlangReflectionBuilder::Build(
    slang::IComponentType* linkedProgram,
    const CompiledProgramContext& context,
    ShaderReflectionIR& output,
    String& error);
  • 只接受已经完成 link 和静态 interface/generic specialization 的 component。
  • 通过 linkedProgram->getLayout(targetIndex, diagnostics) 取得 ProgramLayout；Layout diagnostics 进入 CompileMessage。
  • 先检查所有 EntryPoint 参数类别，再从 Program 的唯一全局参数根开始遍历。

BindingPath 数据结构与解析算法

BindingPath 是 Slang 官方 access-path 模型的 Builder 内部实现。它保存变量布局链和两个“停止累加”的容器边界，不是已经算好的 binding 整数。

struct BindingPathNode
    {
    const slang::VariableLayoutReflection* VarLayout = nullptr;
    const BindingPathNode* Outer = nullptr;
    };

struct BindingPath
{
    const BindingPathNode* Leaf = nullptr;
    const BindingPathNode* DeepestConstantBuffer = nullptr;
    const BindingPathNode* DeepestParameterBlock = nullptr;
};

struct BlockLayoutContext
{
    const slang::TypeLayoutReflection* ContainerTypeLayout; // 根无包装时可空
    const slang::TypeLayoutReflection* ElementTypeLayout;
    Optional<BindingPath> ContainerPath; // uniformSize=0 且无包装时可空
    BindingPath ElementPath;
};

// 节点地址必须在 Builder 完成前保持稳定；普通 Array 扩容会搬移元素，禁止使用。
using BindingPathNodeArena = ChunkedArray<BindingPathNode, 64>;
路径对象是否序列化含义
BindingPath否编译期 Slang occurrence 地址链，只含 VariableLayout 和容器边界。
Type/Member/SubBlock 图是IR 的结构与相对 offset，是运行时名称寻址的唯一数据源。
ShaderVarLocation否；加载时派生运行时的 (blockId, uniformByte) 或 (blockId, rangeIndex, resourceIndex)。
  • Node 由 Builder 的稳定地址 ChunkedArray 分配；Outer 指向更外层，所有 deepest 指针必须为 null 或当前同一链中的节点。Builder 不复制或移动 arena。
  • 两个 deepest 同时存在时，从 leaf 向 root 必须先遇到或同时遇到 DeepestConstantBuffer，然后才可遇到 DeepestParameterBlock。每次 Resolve 前用 IsNullOrNodeInChain() 验证，不依赖 Debug-only assert。
  • 只有 VariableLayout 才能形成 Node。数组元素下标、binding range index、descriptor range index 和整数 offset 都不能伪装成 Node。
  • 枚举某块元素 TypeLayout 的 descriptor ranges 时，Slang descriptor set/range offset 已汇总该类型内部的 Struct/Array 路径；传入 ResolveDescriptorRange() 的 owner path 只到 ElementPath，不得再追加 getBindingRangeLeafVariable()，否则会重复计算字段 offset。
  • 数组元素 Type Record 使用 type-only 递归，不携带 occurrence path；运行时数组下标由 elementByteStride 和 resource range 前缀计算。多维数组保持逐层记录并按行优先逐层乘加。
  • Builder 返回前把所有需要的数据复制到 IR，随后整体销毁 arena；IR 不保存 BindingPath 或 Slang 指针。

Append / MakeRootBlockContext / EnterSingleElementContainer 构造路径与 ConstantBuffer/ParameterBlock 截止点

Append(path, varLayout):
    REQUIRE(varLayout != null)
    node = arena.New({ VarLayout = varLayout, Outer = path.Leaf })
    path.Leaf = node
    return path

MakeRootBlockContext(programLayout):
    globalVar = REQUIRE(programLayout.getGlobalParamsVarLayout())
    occurrencePath = Append(EmptyBindingPath(), globalVar)
    globalType = REQUIRE(globalVar->getTypeLayout())

    IF globalType->getKind() IN { ConstantBuffer, ParameterBlock }:
        return EnterSingleElementContainer(occurrencePath, globalType)

    REQUIRE(globalType->getContainerVarLayout() == null)
    REQUIRE(globalType->getElementVarLayout() == null)
    REQUIRE(ReadFiniteUniformSize(globalType) == 0,
            "Vulkan globals with ordinary data require Slang's
             descriptor-backed container layout")
    return {
        ContainerTypeLayout = null,
        ElementTypeLayout = globalType,
        ContainerPath = null,
        ElementPath = occurrencePath
    }

EnterSingleElementContainer(blockOccurrencePath, containerType):
    REQUIRE(containerType->getKind() IN {
        ConstantBuffer, ParameterBlock })
    REQUIRE(blockOccurrencePath.Leaf != null)

    containerVar = REQUIRE(containerType->getContainerVarLayout())
    elementVar = REQUIRE(containerType->getElementVarLayout())
    REQUIRE(containerVar->getTypeLayout() != null)
    REQUIRE(elementVar->getTypeLayout() != null)

    innerBase = blockOccurrencePath
    innerBase.DeepestConstantBuffer = blockOccurrencePath.Leaf

    subSpaceSize = TRY(ReadFiniteOffset(
        containerVar->getTypeLayout(),
        SubElementRegisterSpace))
    IF subSpaceSize > 0:
        innerBase.DeepestParameterBlock = blockOccurrencePath.Leaf

    return {
        ContainerTypeLayout = containerType,
        ElementTypeLayout = elementVar->getTypeLayout(),
        ContainerPath = Append(innerBase, containerVar),
        ElementPath = Append(innerBase, elementVar)
    }

根 VariableLayout 的 offset 不能丢弃。Vulkan 正常情况下会把含 ordinary data 的全局 scope 反射成自动 ConstantBuffer/ParameterBlock；若 SolarEngine 当前接入 Slang 没有提供 container/element 分解，Builder 不猜测默认 UBO 地址。

ResolveCategory / ResolveDescriptorRange 类别感知累计；最终写入绝对 Target 地址
输入BindingPath、ParameterCategory、TypeLayout 的 descriptor 局部索引
不变量每个值非负且 finite；checked uint64 累加；写 IR 时 narrow uint32
输出ResolvedCategoryOffset / ShaderDescriptorRange
ResolveCategory(path, category):
    REQUIRE(IsNullOrNodeInChain(
        path.DeepestConstantBuffer,
        path.Leaf))
    REQUIRE(IsNullOrNodeInChain(
        path.DeepestParameterBlock,
        path.Leaf))
    result = { Value = uint64(0), Space = uint64(0) }

    IF category == Uniform:
        stop = path.DeepestConstantBuffer
        FOR node = path.Leaf; node != stop; node = node.Outer:
            REQUIRE(node != null)
            result.Value = CHECKED_ADD(
                result.Value,
                ReadFiniteOffset(node.VarLayout, Uniform))
        return result

    REQUIRE(category IN {
        ConstantBuffer, ShaderResource, UnorderedAccess,
        SamplerState, DescriptorTableSlot })

    stop = path.DeepestParameterBlock
    FOR node = path.Leaf; node != stop; node = node.Outer:
        REQUIRE(node != null)
        result.Value = CHECKED_ADD(
            result.Value,
            ReadFiniteOffset(node.VarLayout, category))
        result.Space = CHECKED_ADD(
            result.Space,
            ReadFiniteBindingSpace(node.VarLayout, category))

    FOR node = path.DeepestParameterBlock;
        node != null;
        node = node.Outer:
        result.Space = CHECKED_ADD(
            result.Space,
            ReadFiniteOffset(
                node.VarLayout,
                SubElementRegisterSpace))

    return result

ResolveDescriptorRange(
    typeLayout,
    ownerPath,
    logicalRange,
    setIndex,
    rangeIndex):
    category =
        typeLayout->getDescriptorSetDescriptorRangeCategory(
            setIndex, rangeIndex)
    REQUIRE(CurrentBackendAcceptsDescriptorCategory(category))
    base = TRY(ResolveCategory(ownerPath, category))

    absoluteSet = CHECKED_ADD(
        base.Space,
        ReadFinite(typeLayout->getDescriptorSetSpaceOffset(setIndex)))
    absoluteBinding = CHECKED_ADD(
        base.Value,
        ReadFinite(
            typeLayout->getDescriptorSetDescriptorRangeIndexOffset(
                setIndex, rangeIndex)))
    descriptorCount = CheckedPositiveUint32(
        typeLayout->getDescriptorSetDescriptorRangeDescriptorCount(
            setIndex, rangeIndex))
    slangDescriptorType =
        typeLayout->getDescriptorSetDescriptorRangeType(
            setIndex, rangeIndex)

    return ShaderDescriptorRange {
        Role = TRY(MapDescriptorRole(
            logicalRange,
            slangDescriptorType)),
        Set = CheckedUint32(absoluteSet),
        Binding = CheckedUint32(absoluteBinding),
        ArrayElementBase = 0,
        LogicalElementStride = 1,
        DescriptorType = TRY(MapDescriptorType(
            slangDescriptorType)),
        DescriptorCount = descriptorCount,
        StageMask = TRY(BuildStageMask(
            category, absoluteSet, absoluteBinding)),
        Flags = None
    }

MapDescriptorRole(logicalRange, slangDescriptorType):
    IF logicalRange.InternalRole == Counter:
        return Counter
    IF slangDescriptorType == Sampler AND
       logicalRange.ResourceKind != Sampler:
        return Sampler
    return Primary

// DefaultUniformBuffer 不调用上式，Role 固定为 UniformData。

Vulkan adapter 要求 category 为 DescriptorTableSlot，并把 Space/Value 解释为 set/binding。其他 space-aware 类别由同一通用累加器保留给未来 Target；不同类别的 offset 永不互相相加。

类型构建

  1. 从根块 element type 深度优先访问；Struct 成员保持 Slang 声明顺序。
  2. 把 Slang type kind 映射到五种稳定 TypeKind；interface/generic/pointer/unknown 直接失败。
  3. 读取 ordinary data size 与成员相对偏移；unknown/unbounded size 直接失败。
  4. 读取逻辑 binding range 数量和每个 range 的资源类别、数量、base index；数量必须是正的有限 uint32。
  5. 固定数组记录 element count 和 ordinary byte stride；检查元素类型闭包不含 ParameterBlock。
  6. 按规范结构生成去重 key；具名 Struct 的名称属于 key，匿名 Struct 使用完整成员结构。
  7. 分配连续 typeId，并在退出递归后写入完整记录，检测递归环和非法自引用。

不变量最终去重键不含指针；ID 连续且 root-first
输出ShaderTypeRecord[]
BuildTypeGraph(rootTypeLayout):
    // Pass 1：复制 Slang 信息并验证，不产生最终 ID。
    rawRoot = TRY(ExtractRawType(rootTypeLayout, recursionStack = []))
    TRY(RejectRecursiveOrUnsupportedTypeGraph(rawRoot))

    // Pass 2：先计算完整结构 key，再按 root-first 顺序分配 ID。
    ComputeCanonicalKeysBottomUp(rawRoot)
    internedByKey = {}
    records = []
    rootTypeId = TRY(InternType(rawRoot, internedByKey, records))
    return { RootTypeId = rootTypeId, Records = records }

InternType(raw, internedByKey, records):
    key = raw.CanonicalStructuralKey
    IF internedByKey.Contains(key):
        return internedByKey[key]

    id = records.Count
    internedByKey[key] = id
    records.Add(ReservedRecord(id)) // 首次遇到即占位，保持 root-first。

    record = CommonFields(
        id,
        MapTypeKind(raw.Kind),
        CheckedUint32(raw.UniformByteSize),
        BuildLogicalResourceRanges(raw))

    MATCH raw.Kind:
        Basic:
            record.Basic = TRY(BuildBasicFields(raw))
        Struct:
            FOR member IN raw.MembersInDeclarationOrder:
                memberTypeId = TRY(InternType(member.Type, internedByKey, records))
                record.Members.Add(
                    BuildRelativeMember(member, memberTypeId))
        Array:
            FAIL_IF(raw.ElementCount is UnknownOrUnbounded)
            record.Array = {
                ElementTypeId = TRY(InternType(raw.ElementType, ...)),
                ElementCount = CheckedPositiveUint32(raw.ElementCount),
                ElementByteStride = CheckedUint32(raw.ElementStride)
            }
        Resource:
            record.Resource = TRY(BuildStableResourceFields(raw))
        ParameterBlock:
            FAIL_IF(raw.ElementType.Kind == Array)
            record.ParameterBlock = {
                ContainerKind = MapContainerKind(raw),
                ElementTypeId = TRY(InternType(raw.ElementType, ...))
            }

    records[id] = Move(record)
    return id

两阶段算法既满足“不能用 Slang 指针作为序列化去重身份”，又保证最终 ID 按根开始的首次可达顺序稳定分配。

Logical Resource Range 归一化伪代码

BuildLogicalResourceRanges 先继承子类型语义，再用 Slang 的扁平 range 结果复核
输入RawType + 当前 TypeLayout
不变量OwnerRangeOffset 始终指向当前类型局部主 range
输出ShaderResourceRange[]
BuildLogicalResourceRanges(raw):
    MATCH raw.Kind:
        Basic:
            normalized = []

        Resource:
            normalized = ReadDirectLeafRanges(raw.SlangTypeLayout)
            IF raw.StructuredKind IN { Counter, Append, Consume }:
                counterIndex = CheckedRangeIndex(
                    raw.SlangTypeLayout
                        .getExplicitCounterBindingRangeOffset())
                ownerIndex = FindMainStructuredBufferRange(normalized)
                REQUIRE(counterIndex != ownerIndex)
                REQUIRE(normalized[counterIndex].Count ==
                        normalized[ownerIndex].Count)
                REQUIRE(counterIndex > ownerIndex)
                normalized[counterIndex].InternalRole = Counter
                normalized[counterIndex].OwnerRangeOffset = ownerIndex
                raw.AuxiliaryRanges.Add({
                    Role = Counter,
                    RangeOffset = CHECKED_SUB(
                        counterIndex,
                        ownerIndex)
                })

        ParameterBlock:
            normalized = [
                ContainerRange(
                    kind = raw.ContainerKind,
                    count = 1)
            ]

        Struct:
            normalized = []
            FOR fieldIndex, field IN raw.FieldsInDeclarationOrder:
                child = field.Type.ResourceRanges
                IF child.IsEmpty:
                    REQUIRE(field.ResourceRangeOffset is null)
                    continue

                start = CheckedRangeIndex(
                    raw.SlangTypeLayout
                        .getFieldBindingRangeOffset(fieldIndex))
                REQUIRE(start == normalized.Count)
                field.ResourceRangeOffset = start
                field.ResourceIndex = 0

                FOR childRange IN child:
                    copy = childRange
                    IF copy.OwnerRangeOffset != null:
                        copy.OwnerRangeOffset =
                            CHECKED_ADD(start, copy.OwnerRangeOffset)
                    normalized.Add(copy)

        Array:
            normalized = Copy(raw.ElementType.ResourceRanges)
            FOR range IN normalized:
                range.Count = CHECKED_MUL(
                    range.Count,
                    raw.ElementCount)
                // Range 顺序不变，owner 的局部 range index 不变。

    runningBase = 0
    FOR range IN normalized:
        range.BaseIndex = CheckedUint32(runningBase)
        runningBase = CHECKED_ADD(runningBase, range.Count)

    reflectedCount = raw.SlangTypeLayout.getBindingRangeCount()
    REQUIRE(reflectedCount == normalized.Count)
    FOR i IN [0, reflectedCount):
        REQUIRE(normalized[i].Count ==
                raw.SlangTypeLayout.getBindingRangeBindingCount(i))
        REQUIRE(IsLogicalKindCompatible(
            normalized[i],
            raw.SlangTypeLayout.getBindingRangeType(i),
            raw.SlangTypeLayout.getBindingRangeLeafTypeLayout(i)))

    return normalized

Struct 的 start == normalized.Count 同时验证 Slang 字段 range 偏移与声明顺序拼接一致。数组只放大每条 range 的元素数，不复制 range 记录；counter 的 owner 仍是数组 Type Record 内相同的局部 rangeIndex。

ParameterBlock 构建

  1. 为根全局参数创建 block 0；根块名称为空。
  2. 为每个具体 ConstantBuffer/ParameterBlock 出现位置创建独立 block，即使 elementTypeId 相同。
  3. 读取块的 ordinary data size；大于 0 时必须生成 defaultUniformBuffer，等于 0 时必须为 null。
  4. 按 element type 的 logical resource range 索引创建同数量 rangeBindings。
  5. 使用 Slang binding range 与 descriptor range 查询取得 descriptor count 和 Stage mask；沿 VariableLayout 路径按参数类别累计子布局 offset，最终在叶节点解析为绝对 set/binding。
  6. 块 flavor 递归创建 subBlockId；同一非根 block 只有一个父出现位置，块图必须无环。

Slang 的 binding range 与 descriptor range 是不同层级。实现必须使用 getFieldBindingRangeOffset、binding-range descriptor-set/first-descriptor-range 查询等 API 建立显式映射，不能把两个索引当成同一个索引。

ParameterBlock 与 Range Mapping 伪代码

BuildParameterBlock 计划实现 · 逻辑 binding range 显式映射到 0～N 个 descriptor range
输入BlockLayoutContext（container/element 两条 BindingPath）
不变量每个 logical range 恰好一条 RangeBinding
输出具体 block 实例及递归子块
BuildParameterBlock(context, blockName):
    blockId = ReserveNextBlockId()
    typeLayout = context.ElementTypeLayout
    elementTypeId = TRY(typeGraph.Intern(typeLayout))
    uniformSize = TRY(ReadFiniteUniformSize(typeLayout))

    block = ParameterBlockRecord {
        Id = blockId,
        Name = blockName,
        ElementTypeId = elementTypeId,
        UniformByteSize = uniformSize,
        DefaultUniformBuffer =
            TRY(BuildDefaultUniformDescriptorOrNull(context, uniformSize))
    }

    subObjects = TRY(IndexSubObjectRanges(
        typeLayout,
        ownerPath = context.ElementPath))
    logicalCount = typeLayout.getBindingRangeCount()
    FOR rangeIndex IN [0, logicalCount):
        range = TRY(ReadLogicalBindingRange(typeLayout, rangeIndex))
        FAIL_IF(range.Count is UnknownOrUnbounded)

        IF range.BindingType IN { ConstantBuffer, ParameterBlock }:
            REQUIRE(range.Count == 1) // 块数组禁止。
            subObjectIndex = REQUIRE_EXACTLY_ONE(
                subObjects.ForBindingRange(rangeIndex))
            offsetVar = REQUIRE(
                typeLayout.getSubObjectRangeOffset(subObjectIndex))
            TRY(ReadFinite(
                typeLayout.getSubObjectRangeSpaceOffset(subObjectIndex)))

            containerType = REQUIRE(
                typeLayout.getBindingRangeLeafTypeLayout(rangeIndex))
            REQUIRE(containerType.getKind() ==
                    KindExpectedBy(range.BindingType))
            subOccurrencePath = Append(context.ElementPath, offsetVar)
            subContext = TRY(EnterSingleElementContainer(
                subOccurrencePath,
                containerType))
            subBlockId = TRY(BuildParameterBlock(
                subContext,
                LocalNameOf(
                    typeLayout.getBindingRangeLeafVariable(rangeIndex))))
            mapping = BlockRangeBinding(
                rangeIndex,
                range.ContainerFlavor,
                subBlockId)
        ELSE:
            setIndex = typeLayout.getBindingRangeDescriptorSetIndex(rangeIndex)
            first = typeLayout.getBindingRangeFirstDescriptorRangeIndex(rangeIndex)
            count = typeLayout.getBindingRangeDescriptorRangeCount(rangeIndex)
            descriptors = []

            FOR descriptorOffset IN [0, count):
                descriptor = TRY(ResolveDescriptorRange(
                    typeLayout,
                    context.ElementPath,
                    range,
                    setIndex,
                    first + descriptorOffset))
                REQUIRE(descriptor.DescriptorCount == range.Count)
                descriptors.Add(descriptor)

            FAIL_IF(descriptors.IsEmpty)
            TRY(ValidateSimpleRangeSubObjects(
                range,
                subObjects.ForBindingRange(rangeIndex)))
            mapping = SimpleRangeBinding(rangeIndex, descriptors)

        block.RangeBindings.Add(mapping)

    blocks[blockId] = Move(block)
    return blockId

ValidateSimpleRangeSubObjects(range, subObjects):
    leafType = REQUIRE(range.LeafTypeLayout->getType())
    isStructuredBuffer =
        range.BindingType IN { RawBuffer, MutableRawBuffer } AND
        leafType->getElementType() != null

    IF isStructuredBuffer:
        subObject = REQUIRE_EXACTLY_ONE(subObjects)
        TRY(ReadFinite(subObject.SpaceOffset))
        REQUIRE(subObject.OffsetVarLayout != null)
        // 只验证 Slang shader-object 结构；不创建 SubBlockId。
        return

    REQUIRE(subObjects.IsEmpty)

BuildDefaultUniformDescriptorOrNull(context, uniformSize):
    IF uniformSize == 0:
        return null

    containerPath = REQUIRE(context.ContainerPath)
    address = TRY(ResolveCategory(
        containerPath,
        DescriptorTableSlot))
    return ShaderDescriptorRange {
        Role = UniformData,
        Set = CheckedUint32(address.Space),
        Binding = CheckedUint32(address.Value),
        ArrayElementBase = 0,
        LogicalElementStride = 1,
        DescriptorType = UniformBuffer,
        DescriptorCount = 1,
        StageMask = TRY(BuildStageMask(
            DescriptorTableSlot,
            address.Space,
            address.Value)),
        Flags = None
    }

sub-object range 是第三个独立索引域：先用 getSubObjectRangeBindingRangeIndex() 建立反向索引。ConstantBuffer/ParameterBlock 必须精确一对一并使用 offset VariableLayout 进入子块；StructuredBuffer 可有一个供 Slang shader-object 存储使用的 sub-object，但当前引擎仍把它保存为 simple 资源，不生成 SubBlock。getSubObjectRangeSpaceOffset() 只检查为有限值，不能和 offset VariableLayout 重复叠加。当前路径只有 Slang 官方主 access path；不实现 Falcor 为动态 specialization 保留的 deferred/pending path。

Stage mask 合并

Builder 从联合 linked component 的逐 EntryPoint metadata 得到每个绝对绑定位置的 Stage 使用信息。同一绝对 (set, binding) 在多 Stage 出现时，descriptor type/count/flags 必须一致，Stage mask 取并集；任何其他冲突都使编译失败。

Stage 使用掩码伪代码

BuildStageMask 计划实现 · 使用 IComponentType::getEntryPointMetadata
输入ParameterCategory + 绝对 set/binding
不变量EntryPoint 顺序与 Stage code 顺序一致
输出稳定 Stage 名称数组
PrepareStageUsage(linked, orderedStages):
    metadataByStage = []
    FOR entryPointIndex, stage IN Enumerate(orderedStages):
        metadata, diag = linked.getEntryPointMetadata(
            entryPointIndex,
            targetIndex = 0)
        diagnostics.Append(diag, Context(stage))
        FAIL_IF(metadata == null, "Missing entry-point metadata")
        metadataByStage.Add({ stage, metadata })

BuildStageMask(category, absoluteSet, absoluteBinding):
    mask = []
    FOR item IN metadataByStage:
        used = TRY(item.Metadata.isParameterLocationUsed(
            category,
            spaceIndex = absoluteSet,
            registerIndex = absoluteBinding))
        IF used:
            mask.Add(item.Stage)

    // Layout 仍保留已声明但被目标代码优化掉的逻辑资源；
    // 此时用完整 Program Stage 集作为合法、确定性的可见性上界。
    IF mask.IsEmpty:
        mask = orderedStages

    return StableSort(mask, StableStageOrder)

stageMask 表示 Vulkan Layout 允许访问该 binding 的 Stage 集；对实际使用的资源使用精确 metadata 结果，对所有 Stage 均未使用的已声明资源使用完整 Program Stage 集。metadata 查询失败是编译失败，不静默回退。

4. IR 强校验

ShaderReflectionValidator 同时被 Writer 和 Reader 调用。编译器不能假设“Slang 返回成功”就自动满足引擎契约，运行时也不能信任磁盘文本。

类别必须满足失败信息包含
IDtypeId/blockId 连续、唯一、范围内；所有记录从 root 可达。JSON/IR 路径与非法 ID。
类型Tagged Union 字段严格；稳定枚举已知；size/offset/stride 在 uint32 内；块 Type Record 有且仅有一条 count=1 容器 range。typeId、kind、字段。
数组elementCount 有限且 > 0；不存在无界；数组闭包不含块。成员路径与类型链。
块单根、无环、非根单父；块 elementType 不是 array。blockId 和父 range。
Builder BindingPathdeepest 指针属于当前链；container/element 成对；块 binding range 与 sub-object range 一对一；所有类别累计有限且无 uint64/uint32 溢出。Program、类型/成员路径、category 和 Slang 原值。
UniformuniformByteSize == 0 ⇔ defaultUniformBuffer == null。blockId、size 和 binding。
RangeN 个 logical ranges 对应恰好 N 个 rangeBindings，rangeIndex 完整覆盖；BaseIndex 等于 count 前缀和；counter 的 OwnerRangeOffset 指向同类型主 range，Resource 的正向 RangeOffset 回指同一 counter。blockId、缺失/重复 index 或 owner。
物理描述符count > 0 且等于逻辑 count；Base=0、Stride=1；同 set/binding 只有一个逻辑写入所有者且定义无冲突。set、binding、role 与两个 owner。
不支持项无 Push Constant、EntryPoint uniform/resource 参数、块数组或 unbounded range。Program/Stage/参数或类型路径。
Fingerprint重算结果与 SHA-256 的 64 个小写十六进制字符一致。保存值和计算值。

Validate(ir):
    REQUIRE(ir.Schema == 2)
    REQUIRE(IsContinuousIds(ir.Types))
    REQUIRE(IsContinuousIds(ir.ParameterBlocks))
    REQUIRE(ir.RootBlockId < ir.ParameterBlocks.Count)

    reachableTypes = WalkTypesFromRoot(ir)
    reachableBlocks, parentCount = WalkBlocksFromRoot(ir)
    REQUIRE(reachableTypes.Count == ir.Types.Count)
    REQUIRE(reachableBlocks.Count == ir.ParameterBlocks.Count)
    REQUIRE(parentCount[root] == 0)
    REQUIRE(all non-root parentCount == 1)

    FOR type IN ir.Types:
        TRY(ValidateTaggedUnion(type))
        TRY(ValidateUint32SizesAndOffsets(type))
        TRY(RejectUnboundedAndBlockArrays(type, ir.Types))

    physicalBySetBinding = {}
    FOR block IN ir.ParameterBlocks:
        REQUIRE((block.UniformByteSize == 0) ==
                (block.DefaultUniformBuffer is null))
        IF block.DefaultUniformBuffer != null:
            TRY(ValidateDescriptorAddressing(
                block.DefaultUniformBuffer,
                logicalCount = 1))
            TRY(RegisterUniquePhysicalWriteOwner(
                block.DefaultUniformBuffer,
                owner = UniformOwner(block.Id),
                physicalBySetBinding))

        logicalRanges = ir.Types[block.ElementTypeId].ResourceRanges
        REQUIRE(CoversExactly(
            block.RangeBindings.RangeIndex,
            [0, logicalRanges.Count)))

        FOR mapping IN block.RangeBindings:
            TRY(ValidateFlavorUnion(mapping))
            TRY(ValidateDescriptorAddressing(mapping, logicalRanges))
            TRY(RegisterUniquePhysicalWriteOwner(
                mapping,
                owner = LogicalRangeOwner(block.Id, mapping.RangeIndex),
                physicalBySetBinding))

    expected = ComputePipelineLayoutFingerprint(ir)
    REQUIRE(ir.PipelineLayoutFingerprint == expected)
    return Validated(ir)

Builder 在写 IR 前已把同一 owner、同一物理 binding 的多 Stage 可见性合并为一条 descriptor 记录；Reader 因此把重复物理记录视为非规范或多 owner 冲突，不在加载时猜测覆盖顺序。

5. SLC2 Writer

聚合模型

SLC2Artifact
  format
  programs[]
    programId
    variantGroups[]
    targets[]
      meta { platform, backend, shaderModel }
      variants[]
        variant
        layout
        stages[]
          { entryPoint, stage, code }
  • 一个 SLC2 对应一个 Shader Resource；顶层不保存 shaderId 或资源路径。
  • ProgramId 位于 programs[] 元素内；Target 在 Program 内聚合多个 Variant。
  • Layout 位于 Variant 层并由全部 Stage 共享；Stage 不复制 Layout。
  • 没有独立 names[]；运行时从 Struct member 局部名称构建完整路径。
  • 不保存 source/import 路径、DependencyIndex、diagnostics、默认资源或运行时生命周期信息。

JSON 写入规则

  • 使用 SolarEngine 当前 JSON Writer；字段调用顺序就是规范顺序。
  • 输出无 BOM UTF-8、LF、最终换行；字符串必须是有效 UTF-8，禁止平台本地编码。
  • 代码 blob 使用 JSON Base64 字符串；另存明确的 encoding 和完整 SHA-256，读取时先 Base64 解码再验证 hash。
  • SPIR-V 首先检查长度是 4 的倍数、magic 为 0x07230203，并由 Slang 验证；测试示例必须是完整 Module，不使用只有 4 字节 magic 的伪产物。
  • 写入前执行 IR Validator；写入后立即用运行时 SLC2Reader 读取同一字节并深比较关键语义。
  • Writer 不写文件。调用者拿到完整 byte array 后才执行原子文件替换。

确定性 Writer 伪代码

SLC2Writer.WriteDeterministic 计划实现 · 固定字段顺序，不遍历无序 Dictionary
输入完整 SLC2Artifact
不变量相同输入字节完全一致；不写路径/时间/指针
输出UTF-8 JSON byte[]
WriteDeterministic(artifact):
    canonical = TRY(CanonicalizeAndValidateArtifact(artifact))
    buffer = Utf8StringBuffer()
    json = PrettyJsonWriter(buffer, indent = Tab, newline = LF)

    json.BeginObject()
    WriteFormat(json, canonical.Format)

    json.Key("programs")
    json.BeginArray()
    FOR program IN StableSort(canonical.Programs, ProgramId):
        json.BeginObject()
        json.Field("programId", program.ProgramId)
        WriteVariantGroups(json, program.VariantGroupsInDeclarationOrder)

        json.Key("targets")
        json.BeginArray()
        FOR target IN StableSort(program.Targets, CanonicalTargetTuple):
            json.BeginObject()
            WriteTargetMeta(json, target.Meta)
            json.Key("variants")
            json.BeginArray()

            FOR variant IN StableSort(target.Variants, VariantText):
                json.BeginObject()
                WriteVariantText(json, variant.CanonicalText)
                WriteLayout(json, variant.ValidatedReflectionIR)
                WriteStages(
                    json,
                    StableSort(variant.Stages, StableStageOrder),
                    codeEncoder = bytes => {
                        Encoding = "base64",
                        Hash = Sha256LowerHex(bytes),
                        Data = Base64WithoutLineBreaks(bytes)
                    })
                json.EndObject()

            json.EndArray()
            json.EndObject()
        json.EndArray()
        json.EndObject()
    json.EndArray()
    json.EndObject()

    bytes = NormalizeNewlinesToLf(buffer.Bytes())
    AppendFinalLfIfMissing(bytes)
    TRY(SLC2Reader.ReadAndValidate(bytes)) // 同款 Reader 自检。
    return bytes

确定性要求

  • 同一输入、CompilerBuildTag 和 SolarEngine 当前 Slang 编译器标识连续编译两次，SLC2 字节必须完全一致。
  • 所有数组按编译器实施文档规定排序；JSON Object 字段顺序固定。
  • 禁止把内存地址、构建时间、绝对路径、随机 ID 或原生枚举数值写入缓存。
  • Base64 不换行；SHA-256 统一为 64 个小写十六进制字符。

6. SLC2 Reader 与错误模型

读取阶段

  1. Parse JSON；拒绝语法错误、非 UTF-8 和根类型错误。
  2. 校验 format.magic == "SLC2"、major 精确匹配；未知 major 拒绝，已知 major 的更高 minor 按兼容规则处理。
  3. 逐字段读取并执行整数范围、必需字段、Tagged Union 和稳定枚举检查。
  4. 解码 Stage code，验证 code hash 与 Target 代码基本格式。
  5. 执行完整 IR Validator、可达性、range mapping 和块数组检查。
  6. 重建规范物理布局并验证 pipelineLayoutFingerprint。
  7. 构造不可变 ShaderProgramArtifact；仅全部成功后对调用者可见。

严格 Reader 伪代码

SLC2Reader.ReadAndValidate 计划实现 · 不使用允许 trailing comma 的宽松 Parse flags
输入不可信 SLC2 UTF-8 bytes
不变量先完整验证，后发布不可变对象
输出ShaderProgramArtifact
ReadAndValidate(bytes):
    TRY(ValidateUtf8WithoutBom(bytes))
    document = TRY(ParseRapidJsonWithExplicitStrictFlags(
        bytes,
        validateEncoding = true,
        allowTrailingCommas = false,
        requireEndOfInput = true))
    REQUIRE(document.IsObject, path = "/")

    root = StrictObjectReader(document, path = "/")
    format = TRY(ReadExactFormat(root.RequiredObject("format")))
    REQUIRE(format.Magic == "SLC2")
    REQUIRE(format.Major == 2)

    programs = []
    seenProgramIds = Set()
    FOR programNode IN root.RequiredArray("programs"):
        program = TRY(ReadProgram(programNode))
        REQUIRE(seenProgramIds.Add(program.ProgramId))
        programs.Add(program)
    root.RejectUnknownRequiredOrDuplicateFields()

    artifact = ShaderProgramArtifact(format, programs)
    FOR program IN artifact.Programs:
        TRY(ValidateVariantGroups(program))
        FOR target IN program.Targets:
            TRY(ValidateTargetAndRegenerateTargetKey(target))
            FOR variant IN target.Variants:
                TRY(ShaderReflectionValidator.Validate(variant.Layout))
                FOR stage IN variant.Stages:
                    bytes = TRY(Base64DecodeStrict(stage.Code.Data))
                    REQUIRE(Sha256LowerHex(bytes) == stage.Code.Hash)
                    TRY(ValidateTargetCode(target.Meta, bytes))

    return Freeze(artifact)

若 SolarEngine 通用 Json 解析配置允许 trailing commas，SLC2 Reader 必须显式选择严格解析 flags，保证格式契约不会因引擎通用 JSON 宽松策略而变化。

严格字段策略

  • 缺失必需字段、重复 Program/Target/Variant/Stage、未知枚举、非法 null 都是缓存损坏。
  • 同一 major 内允许忽略未知的可选字段，但 Writer 当前不产生扩展字段；改变必需语义必须提升 major。
  • Reader 错误包含 JSON Pointer 风格路径，例如 /programs/0/targets/0/variants/1/layout/types/3。
  • 加载失败不尝试调用 Slang、SPIR-V reflection 或旧 cache reader 修复；由上层决定重新编译。

7. PipelineLayoutFingerprint 实现

规范物理记录

  1. 从 rootBlock 遍历所有可达 block，收集 defaultUniformBuffer 和 simple range 的全部 descriptorRanges。
  2. 把 defaultUniformBuffer 归一化为普通 descriptor 记录。
  3. 按绝对 (set, binding) 合并；descriptorType/count/flags/immutable sampler 状态必须相同，Stage mask 取并集。
  4. set、binding 数值升序；空 set 仍参与 setCount 与规范文本。
  5. 以 SOLAR-PIPELINE-LAYOUT/v1 开头、稳定小写枚举、十进制整数、LF 与最终 LF 生成文本。
  6. 计算 LowerHex(SHA-256(UTF8(text)))。

Fingerprint 伪代码

ComputePipelineLayoutFingerprint(ir):
    merged = Map<(set, binding), PhysicalBinding>()

    FOR block IN WalkReachableBlocks(ir.RootBlockId):
        IF block.DefaultUniformBuffer != null:
            TRY(MergePhysical(
                merged,
                NormalizeUniformBuffer(block.DefaultUniformBuffer)))

        FOR mapping IN block.RangeBindings:
            CONTINUE_IF(mapping.Flavor != Simple)
            FOR descriptor IN mapping.DescriptorRanges:
                TRY(MergePhysical(merged, descriptor))

    setCount = merged.IsEmpty ? 0 : Max(merged.Keys.Set) + 1
    text = "SOLAR-PIPELINE-LAYOUT/v1\n"
    text += "backend=vulkan\n"
    text += "pipelineFlags=-\n"
    text += "setCount=" + Decimal(setCount) + "\n"

    FOR set IN [0, setCount):
        text += "set=" + Decimal(set) + ";flags=-\n"
        FOR binding IN StableSort(merged.WhereSet(set), BindingNumber):
            text += CanonicalBindingLine(
                binding,
                StableStageOrder,
                StableFlagOrder)

    return LowerHex(SHA256(Utf8NoBom(text)))

MergePhysical 只合并 descriptorType/count/flags/immutable-sampler 状态完全一致的记录，并对 StageMask 求并集；其他差异立即失败。

明确不参与 Hash

ProgramId、Variant、EntryPoint、代码、成员/资源名、type/block/range ID、uniform offset、resourceIndex、role、arrayElementBase、logicalElementStride 和当前绑定对象都不进入 fingerprint。它只表达后端 Pipeline Layout 的精确物理相等。

运行时复用

fingerprint 只作为缓存第一层 key。hash 命中后必须深比较规范化物理记录，再复用 Vulkan PipelineLayout；这同时防止 hash 碰撞和错误 Writer 产生的假相等。
