# 编译器实现

目标：新建独立 Slang 编译事务，从 `ShaderCompileRequest` 生成完整 SLC2。编译器只产出内存结果，不写正式缓存文件。

## 替换边界

新路径不继承旧 `ShaderCompiler` 基类。旧抽象围绕 `ShaderMeta`、逐 Stage permutation 和二进制 GPU cache 设计，不适合 SLC2。

新增协调器：

- `SlangShaderCompiler`
- 公开入口仍由 `ShadersCompilation` 提供。
- 旧 `Compile(ShaderCompilationOptions&)` 可过渡共存。
- 新入口不调用旧 Parser、profile compiler 或 glslang fallback。

## 新增文件

| 文件 | 职责 |
| --- | --- |
| `ShaderCompileTypes.h` | request、target、variant、status、result |
| `SlangShaderCompiler.h/.cpp` | 请求级全有或全无事务 |
| `SlangSessionFactory.h/.cpp` | GlobalSession/Session、Target、宏、Slang 文件系统挂接 |
| `SlangShaderFileSystem.h/.cpp` | 编译侧 import/include 路径解析；首版以根 Shader 文件目录为默认查找根，后续扩展引擎虚拟路径 |
| `SlangProgramDiscovery.h/.cpp` | Program、Stage、Variant Group 发现 |
| `ShaderVariantPlanner.h/.cpp` | Variant 展开、规范化、去重 |
| `SlangTargetPolicy.h/.cpp` | TargetKey 与 Slang target desc |
| `SlangDiagnosticSink.h/.cpp` | Warning/Error 聚合 |

## 公开 API

```cpp
enum class GraphicsBackend : uint8
{
    Vulkan,
};

struct ShaderCompileTarget
{
    PlatformType Platform;
    GraphicsBackend Backend;
    ShaderModel Model;
};

struct ShaderVariantRequest
{
    Array<String> Defines;
};

struct ShaderProgramVariantSelection
{
    String ProgramId;
    Array<ShaderVariantRequest> Variants;
};

struct ShaderCompileRequest
{
    String ResourcePath;
    StringAnsi Source;
    Array<ShaderCompileTarget> Targets;
    Array<ShaderProgramVariantSelection> VariantSelections;
    bool TreatWarningsAsErrors;
};

enum class ShaderCompileStatus : uint8
{
    Success,
    Failed,
};

struct ShaderCompileResult
{
    ShaderCompileStatus Status;
    String CompileMessage;
    Array<byte> SLC2Data;
};
```

## API 语义

- `Targets` 至少一项，按规范 `TargetKey` 去重。
- 首版只接受受支持 Host 上的 Vulkan。
- `VariantSelections` 为空：编译所有发现 Program 的完整笛卡尔积。
- `VariantSelections` 非空：只编译列出的 Program 和组合。
- Selection 内 `Variants` 不能为空。
- 显式 `Defines = {}` 是一个真实请求，会经过默认补全。
- 请求不传入 `SearchPaths`。根 Shader 文件、import 和 include 的解析由编译侧 `SlangShaderFileSystem` 统一处理，避免调用方搜索路径污染 Shader 编译身份。
- Slang 的 `const char*` API 边界使用 `StringAnsi` 桥接；宏名、入口名、源码路径和源码文本不得默认以 `std::string` 作为生命周期持有对象。
- 控制流分支必须显式使用 `{}`，包括单语句 `if` / `else` / `for` / `while`。
- 请求不暴露优化、调试、矩阵布局、SPIR-V 版本、capability 或 binding shift。
- Success 必须带完整、UTF-8、通过 self-read 的 SLC2。
- Failed 必须清空 `SLC2Data`。

## 编译独立性

编译器必须可在没有以下对象时独立执行：

- `ShaderProgramInstance`
- GPU 设备
- Vulkan backend
- descriptor writer
- 资源绑定状态

验收依据是：

- 完整 `SLC2Data`
- 共享无后端 `SLC2Reader` self-read
- semantic manifest
- byte determinism

## 总事务

```text
Compile(request):
  result = Failed / empty
  diagnostics = DiagnosticSink(resourcePath)

  validated = ValidateAndCanonicalizeRequest(request)
  baseline  = DiscoverBaselinePrograms(validated)
  plan      = BuildCompilePlan(validated, baseline)

  artifact = NewSLC2Artifact(format=2.0)

  for group in plan.GroupBy(TargetKey, Variant):
    session = CreateVariantSession(group)
    module  = LoadAndVerifyModule(session, baseline)

    for unit in group.Units:
      compiled = CompileProgramUnit(session, module, unit)
      artifact.Add(compiled)

  if diagnostics.HasError:
    return Failed

  if request.TreatWarningsAsErrors && diagnostics.HasWarning:
    return Failed

  bytes = SLC2Writer.WriteDeterministic(artifact)
  SLC2Reader.ReadAndValidate(bytes)

  result = Success(diagnostics.Text, bytes)
```

编译器不写文件。调用者在 Success 后执行临时文件、flush、rename 和回滚。

## 单 Program 编译单元

```text
CompileProgramUnit(session, module, unit):
  components = [module]
  entryPointOrder = []

  for stageDecl in StableStageOrder(unit.Program.Stages):
    entryPoint = module.findAndCheckEntryPoint(
      stageDecl.EntryPoint,
      ToSlangStage(stageDecl.Stage))
    ValidateEntryPointParameters(entryPoint)
    components.Add(entryPoint)
    entryPointOrder.Add(stageDecl)

  composite = session.createCompositeComponentType(components)
  linked = composite.link()

  layout = linked.getLayout(targetIndex=0)
  reflectionIR = SlangReflectionBuilder.Build(linked, layout, unit)

  for stageDecl in entryPointOrder:
    code = linked.getEntryPointCode(index, targetIndex=0)
    ValidateTargetCode(unit.Target, code)
    stages.Add(StageRecord(stageDecl, code))

  ShaderReflectionValidator.Validate(reflectionIR)
  return CompiledProgramUnit(identity, reflectionIR, stages)
```

全部 Stage 必须来自同一个 linked component。禁止逐 Stage 链接后猜测 binding 兼容。

## Program 发现

基线发现使用空 Variant 宏环境：

- 不定义任何 `SHADER_MACRO` 成员。
- SolarEngine Slang 标准头提供 `SHADER_PROGRAM`、`SHADER_VS` 等声明宏。
- 使用 `IModule::getModuleReflection()`。
- 只遍历根 Module 直接声明。
- 不递归 namespace。
- 不发现 imported Module 中的 Program。

Program marker：

- `SHADER_PROGRAM` 展开 `SolarShaderProgram` Attribute。
- `ProgramId = DeclReflection::getName()`，立即复制 UTF-8。
- 不使用 `SimpleName` 或 Slang 私有 AST。
- 同一 Shader Resource 中 ProgramId 不能重复。

Stage 契约：

- Compute：必须且只能一个 CS。
- Graphics：必须有 PS；每种 Stage 最多一个。
- HS/DS 必须成对。
- CS 不能混入 graphics Program。
- EntryPoint 不需要 `[shader]`。
- EntryPoint 参数只允许 varying/system-value。

Variant Session 重新发现后，Program/Stage/宏组结构必须与基线一致。

## Variant Planner

规则：

- `SHADER_MACRO(A, B)` 是必选互斥组；缺省选择第一个宏。
- `SHADER_MACRO(_, FOG_ON)` 包含空选择；缺省不定义宏。
- `_` 参与笛卡尔积，但不写入 `variant` 字符串。
- 实际宏只有定义/未定义，无宏值。
- Program 内实际宏名全局唯一。

规范化：

```text
NormalizeVariant(groups, requestedDefines):
  reject unknown macro
  reject "_"
  reject NAME=VALUE
  reject multiple members in one group
  fill missing required groups with first member
  keep missing "_" groups undefined
  sort actual macro names by UTF-8 bytes
  join with ";"
  empty set -> ""
```

## Target 策略

`TargetKey` 只由三元组决定：

```text
Platform x Backend x ShaderModel
```

Vulkan 首版输出 SPIR-V。SPIR-V 版本、Vulkan capability、优化、调试、矩阵布局、浮点模式和 binding shift 都由版本化 `SlangTargetPolicy` 固定，不进入请求参数。

## 确定性排序

| 集合 | 顺序 |
| --- | --- |
| Program | `ProgramId` UTF-8 字节序 |
| Target | `platform, backend, shaderModel` 规范元组 |
| Variant | `variant` 字符串 UTF-8 字节序 |
| Stage | VS、HS、DS、GS、PS、CS |
| Type/Block | 从 rootBlock 深度优先 |
| JSON 字段 | Writer 固定代码顺序 |

## 诊断与失败

- Warning/Error 保持调用顺序。
- Slang diagnostics 与引擎校验错误合入同一 `CompileMessage`。
- 不做模糊去重。
- 任一 Program/Target/Variant/Stage 失败，整个请求 Failed。
- Failed 时 `SLC2Data` 必须为空。
- Warning only 且未启用 `TreatWarningsAsErrors` 时可以 Success。
