2. 公开编译 API

请求与结果

enum class GraphicsBackend : uint8
{
    Vulkan,
    // D3D12 / WebGPU 后续加入稳定枚举和值字符串映射。
};

struct ShaderCompileTarget
{
    PlatformType Platform;
    GraphicsBackend Backend;
    ShaderModel Model;
};

struct ShaderVariantRequest
{
    Array<String> Defines; // 只保存宏名；空集合是一条显式 Variant。
};

struct ShaderProgramVariantSelection
{
    String ProgramId;
    Array<ShaderVariantRequest> Variants; // 必须非空。
};

struct ShaderCompileRequest
{
    String ResourcePath;              // 引擎虚拟资源路径。
    StringAnsi Source;                // 根 Module 的 UTF-8 Slang 源码。
    Array<ShaderCompileTarget> Targets;
    Array<ShaderProgramVariantSelection> VariantSelections;
    bool TreatWarningsAsErrors;
};

enum class ShaderCompileStatus : uint8
{
    Success,
    Failed,
};

struct ShaderCompileResult
{
    ShaderCompileStatus Status;
    String CompileMessage;
    Array<byte> SLC2Data;
};

公开语义

  • Targets 至少一项，按规范 TargetKey 去重；首版只接受受支持 Host 上的 Vulkan。
  • VariantSelections 为空表示为所有发现 Program 编译完整笛卡尔积；非空时只编译列出的 Program 和组合。
  • Selection 的 Variants 不能为空；显式 Defines = {} 表示一条会经过默认补全的组合。
  • 请求不传入 SearchPaths；根 Shader 文件、import 和 include 的解析由编译侧 SlangShaderFileSystem 统一处理，避免调用方搜索路径污染 Shader 编译身份。
  • Slang 的 const char* API 边界使用 StringAnsi 桥接；宏名、入口名、源码路径和源码文本不得默认以 std::string 作为生命周期持有对象。
  • 控制流分支必须显式使用 {}，包括单语句 if / else / for / while。
  • 请求不暴露优化级别、调试信息、matrix layout、SPIR-V 版本、capability 或 binding shift，这些都属于版本化 Target 策略。
  • Success 必须携带一份完整、UTF-8、通过自读校验的 SLC2；Failed 必须清空 SLC2Data。
  • Warning 和 Error 保持原始顺序合入一个 CompileMessage；不返回结构化 diagnostics 或部分结果。

最终入口

void ShadersCompilation::Compile(
    const ShaderCompileRequest& request,
    ShaderCompileResult& result)
{
    result = {};
    SlangShaderCompiler compiler;
    compiler.Compile(request, result);
    // 文件提交不在 compiler 内发生。
}

编译器本身只产生内存结果。资产导入器或缓存服务在 Status == Success 后负责临时文件、flush 和 rename；这保证编译失败不会破坏现有有效缓存。该入口必须能在没有 ShaderProgramInstance、GPU 设备、Vulkan backend 和资源绑定状态的进程中独立执行，编译验收以完整 SLC2Data、self-read、语义 manifest 和确定性为准。

公开入口伪代码

CompileShaderResource 计划实现 · 请求级全有或全无事务
输入一个 Shader Resource、多个 Target、可选 VariantSelections
不变量失败时 SLC2Data 为空；旧缓存不在函数内改写
输出最小 ShaderCompileResult
Compile(request, out result):
    result = {
        Status = Failed,
        CompileMessage = "",
        SLC2Data = {}
    }
    diagnostics = DiagnosticSink(request.ResourcePath)

    validated = TRY_OR_FINISH(
        ValidateAndCanonicalizeRequest(request),
        diagnostics,
        result)

    baseline = TRY_OR_FINISH(
        DiscoverBaselinePrograms(validated, diagnostics),
        diagnostics,
        result)

    plan = TRY_OR_FINISH(
        BuildCompilePlan(validated, baseline),
        diagnostics,
        result)

    artifact = NewSLC2Artifact(format = 2.0)
    FOR sessionGroup IN plan.GroupBy(TargetKey, Variant):
        session = TRY_OR_FINISH(
            CreateVariantSession(sessionGroup),
            diagnostics,
            result)
        module = TRY_OR_FINISH(
            LoadAndVerifyModule(session, baseline),
            diagnostics,
            result)

        FOR unit IN sessionGroup.Units:
            compiled = TRY_OR_FINISH(
                CompileProgramUnit(session, module, unit),
                diagnostics,
                result)
            artifact.Add(compiled)

    IF diagnostics.HasError OR
       (request.TreatWarningsAsErrors AND diagnostics.HasWarning):
        return FinishFailed(diagnostics, result)

    bytes = TRY_OR_FINISH(
        SLC2Writer.WriteDeterministic(artifact),
        diagnostics,
        result)
    TRY_OR_FINISH(SLC2Reader.ReadAndValidate(bytes), diagnostics, result)

    result.Status = Success
    result.CompileMessage = diagnostics.Text()
    result.SLC2Data = Move(bytes)

伪代码中的 TRY_OR_FINISH 只修改公开 result，不写磁盘；原子文件替换始终由调用者在 Success 后执行。

3. 编译事务与调用顺序

  1. ValidateRequest：规范化 ResourcePath，校验 Target 唯一性、请求大小和 UTF-8 源码。
  2. DiscoverPrograms：以空 Variant 宏创建基线 Session，加载根 Module，只读取 Module 根声明。
  3. BuildPlan：校验 Program/Stage/宏组，展开全部 Variant 或规范化显式选择，形成有序 CompileUnit 列表。
  4. CompileUnit：为每个 Target × Program × Variant 创建 Variant Session、重新加载 Module、查找入口并创建 composite component。
  5. Link：一次链接同一 Program 的全部 Stage，得到共享 linked component；失败时收集 diagnostics 并终止事务。
  6. Emit：从 linked component 取得共享 Layout，并为每个 EntryPoint 取得目标代码 blob。
  7. BuildIR：把 Slang Layout 转为引擎 ShaderReflectionIR，执行所有不支持项和映射完整性校验。
  8. Aggregate：按确定性顺序聚合 Program、Target、Variant、Layout 与 Stage code。
  9. WriteAndSelfRead：生成 SLC2 UTF-8 JSON，再立即用共享的无后端 SLC2Reader 严格读取和重算 fingerprint；该 reader 不依赖 Vulkan、GPU 资源或运行时 Program 对象。
  10. CommitResult：仅在全部步骤成功后设置 Success；否则清空数据并返回完整错误文本。

首版每次都实际编译请求中的完整单元。跨调用的 source/import 内容命中、DependencyIndex、import 反向索引和孤儿缓存清理不在本实施范围；不得在这里先引入一个未设计的半成品缓存索引。

完整 Program 编译单元伪代码

CompileProgramUnit 计划实现 · Module + Program 全部 EntryPoint 联合链接
输入Variant Session、已加载 Module、Program 声明
不变量所有 Stage 来自一个 linked component
输出共享 Layout + Stage code records
CompileProgramUnit(session, module, unit):
    components = [module]
    entryPointOrder = []

    FOR stageDecl IN StableStageOrder(unit.Program.Stages):
        entryPoint, diag = module.findAndCheckEntryPoint(
            stageDecl.EntryPoint,
            ToSlangStage(stageDecl.Stage))
        diagnostics.Append(diag, Context(unit, stageDecl.Stage))
        FAIL_IF(entryPoint == null, "EntryPoint check failed")
        TRY(ValidateEntryPointParameters(entryPoint, stageDecl))

        components.Add(entryPoint)
        entryPointOrder.Add(stageDecl)

    composite, diag = session.createCompositeComponentType(components)
    diagnostics.Append(diag, Context(unit))
    FAIL_IF(composite == null, "Cannot create Program component")

    linked, diag = composite.link()
    diagnostics.Append(diag, Context(unit))
    FAIL_IF(linked == null, "Program link failed")

    // ProgramLayout 的生命周期绑定到 linked。
    slangLayout, diag = linked.getLayout(targetIndex = 0)
    diagnostics.Append(diag, Context(unit))
    reflectionIR = TRY(SlangReflectionBuilder.Build(linked, slangLayout, unit))

    stages = []
    FOR index, stageDecl IN Enumerate(entryPointOrder):
        code, diag = linked.getEntryPointCode(index, targetIndex = 0)
        diagnostics.Append(diag, Context(unit, stageDecl.Stage))
        TRY(ValidateTargetCode(unit.Target, code))
        stages.Add(StageRecord(stageDecl, CopyBytes(code)))

    TRY(ShaderReflectionValidator.Validate(reflectionIR))
    return CompiledProgramUnit(unit.Identity, reflectionIR, stages)

任何 Stage 检查、link、codegen 或反射失败都丢弃整个 ProgramId × TargetKey × Variant 单元。

确定性排序

集合写入顺序
ProgramProgramId UTF-8 字节序。
Target规范化 platform, backend, shaderModel 三元组顺序。
Variant规范化 variant 字符串 UTF-8 字节序。

4. Program 发现与入口检查

基线 Session

  • SessionDesc.preprocessorMacros 不包含任何 Variant 宏。
  • SolarEngine Shader 接口头中的 SHADER_PROGRAM、SHADER_VS 等声明宏正常可见，但它们不是 Variant。
  • 调用 ISession::loadModuleFromSource 加载根 Module；load diagnostics 即使没有使调用失败，也必须进入 CompileMessage。
  • 使用 IModule::getModuleReflection()，只遍历其直接 DeclReflection::getChild(i)；不递归 namespace，也不枚举 import 的 Module。

Attribute 解析

SHADER_PROGRAM 首先展开一个零参数 SolarShaderProgram Attribute，它是唯一的 Program marker；marker struct 上可重复出现 SolarShaderStage 与 SolarShaderMacroGroup Attribute。宿主用 DeclReflection 枚举直接声明，通过 SolarEngine 当前 Slang 公共 API decl->getName() 取得并复制名称，再对 Struct 调用 decl->getType()，通过 TypeReflection::getUserAttributeCount()、getUserAttributeByIndex() 和 getArgumentValueString() 读取字符串；不把成员函数当入口。

SHADER_PROGRAM(MyProgram,
    SHADER_VS(MyVS)
    SHADER_PS(MyPS)
    SHADER_MACRO(MATERIAL_LIT, MATERIAL_UNLIT)
    SHADER_MACRO(_, FOG_ON)
);
  • ProgramId 是 DeclReflection::getName() 返回并立即复制的 marker struct 简单声明名 MyProgram，区分大小写；返回 null 或空字符串时失败。即使 marker 没有任何 Stage，也必须被发现后按 Stage 契约报错，不能静默跳过。
  • 同一 Shader Resource 中 ProgramId 重复直接失败；namespace 不参与身份。
  • Compute Program 必须且只能有一个 CS，不能混入 graphics Stage。
  • Graphics Program 每种 Stage 最多一个，必须有 PS；HS 和 DS 必须同时存在；不得含 CS。
  • 声明结构必须在所有 Variant 下稳定。Variant Session 重新发现后若 Program/Stage/宏组与基线不同，视为 Shader 接口错误。

按名称检查入口

  • 对每个声明调用 IModule::findAndCheckEntryPoint(entryPointName, SlangStage, ...)，不要求函数带 [shader]。
  • 把 Module 与该 Program 的全部 EntryPoint 交给 ISession::createCompositeComponentType，然后调用 link。
  • Graphics 的 Layout 只能从这个联合 linked component 获取，禁止逐 Stage 独立链接后合并 binding。
  • 检查 EntryPoint 参数，只允许 varying/system-value 输入输出；发现 uniform/resource 参数时报告 Program、Stage、入口和参数名。

Program 发现伪代码

DiscoverPrograms 计划实现 · 只遍历根 Module 的直接声明
输入空 Variant 宏环境中的 IModule
不变量不递归 namespace；不遍历 imported Module
输出已校验、按 ProgramId 排序的 ProgramDecl[]
DiscoverPrograms(module):
    root = module.getModuleReflection()
    programsById = {}

    FOR childIndex IN [0, root.getChildrenCount()):
        decl = root.getChild(childIndex)
        CONTINUE_IF(decl == null)
        CONTINUE_IF(decl.getKind() != DeclReflection::Kind::Struct)

        programType = decl.getType()
        FAIL_IF(programType == null, "Struct type reflection unavailable")
        attributes = ReadAttributes(programType)
        CONTINUE_IF(NOT attributes.ContainsSolarProgramMarker)

        programName = decl.getName()
        FAIL_IF(programName == null OR programName[0] == '\0',
                "Program declaration has no name")
        programId = CopyUtf8(programName)
        FAIL_IF(programsById.Contains(programId),
                "Duplicate ProgramId", programId)

        program = ProgramDecl(programId)
        FOR attribute IN attributes.InSourceOrder:
            MATCH attribute:
                SolarShaderStage(stageText, entryPointText):
                    program.AddStage(
                        ParseStableStage(stageText),
                        ValidateIdentifier(entryPointText))
                SolarShaderMacroGroup(membersText):
                    program.AddVariantGroup(
                        ParseMacroGroupWithoutExpansion(membersText))

        TRY(ValidateStageContract(program))
        TRY(ValidateVariantGroupDeclarations(program))
        program.Signature = HashCanonicalDeclaration(program)
        programsById.Add(programId, program)

    return StableSort(programsById.Values, by = ProgramId)

DeclReflection::getName() 是 SolarEngine 当前接入 Slang 的真实公共 API；不存在 SimpleName。返回指针只在 Slang 反射对象有效期内借用，因此在继续处理前复制。Variant Session 重新加载 Module 后再次计算 Signature；与基线不同即说明声明被 Variant 宏条件化，编译失败。

5. Variant Planner

内部模型

struct ShaderVariantGroup
{
    Array<StringAnsi> Members; // 不含 "_"，保留声明顺序。
    bool HasUndefinedChoice;
    StringAnsi DefaultMember;  // 含 "_" 时为空，否则 Members[0]。
};

struct PlannedVariant
{
    Array<StringAnsi> Defines; // 已排序、无重复，不含 "_"。
    StringAnsi CanonicalText;  // 例如 "FOG_ON;MATERIAL_LIT"。
};

规划算法

  1. 按逗号切分 Attribute 保存的原始 token，trim ASCII 空白，拒绝空项。
  2. 每组原始选项至少两个；_ 每组最多一次，实际宏名符合 [A-Za-z_][A-Za-z0-9_]*。
  3. 同一 Program 中实际宏名不得跨组重复，避免调用者无法判断归属。
  4. 全量模式对“原始选择项”做笛卡尔积，所以 SHADER_MACRO(_, FOG_ON) 产生 "" 与 "FOG_ON"。
  5. 显式模式中，缺少必选组补第一个成员；缺少含 _ 的组选择不定义。
  6. 拒绝 NAME=VALUE、未知宏、同组多选和请求中的 _。
  7. 把实际宏按 UTF-8 字节序排序并以分号连接；排序发生在序列化前，因此调用者输入顺序不影响匹配。
  8. 按 CanonicalText 去重并排序；Variant 数量乘法必须做溢出检查和项目上限检查。

Variant 规划伪代码

BuildProgramVariants 计划实现 · 全量笛卡尔积与显式选择共用 Normalize
输入Program 宏组；可选请求 Defines 集合
不变量宏无值；一个组最多选择一个；“_”不进入 Defines
输出按 CanonicalText 排序且去重的 PlannedVariant[]
BuildProgramVariants(program, optionalSelection):
    groups = TRY(ParseAndValidateGroups(program.VariantGroups))

    IF optionalSelection is absent:
        rawChoices = [[]]
        FOR group IN groups:
            next = []
            FOR prefix IN rawChoices:
                FOR choice IN group.SourceChoices: // 包含 "_" 状态
                    next.Add(prefix + choice)
            FAIL_IF_MUL_OVERFLOW_OR_LIMIT(next.Count)
            rawChoices = Move(next)
    ELSE:
        FAIL_IF(optionalSelection.Variants.IsEmpty)
        rawChoices = optionalSelection.Variants.Select(v => v.Defines)

    unique = Map<CanonicalText, PlannedVariant>()
    FOR raw IN rawChoices:
        selectedByGroup = TRY(ClassifyRequestedMacros(groups, raw))
        defines = []

        FOR group IN groups:
            IF selectedByGroup.Has(group):
                choice = selectedByGroup[group]
            ELSE IF group.HasUndefinedChoice:
                choice = Undefined
            ELSE:
                choice = group.Members[0]

            IF choice != Undefined:
                defines.Add(choice)

        StableSort(defines, Utf8ByteOrder)
        canonical = Join(defines, ";")
        unique.InsertIfAbsent(canonical, PlannedVariant(defines, canonical))

    return StableSort(unique.Values, by = CanonicalText)

SHADER_MACRO(_, FOG_ON) 的 SourceChoices 数量是 2，因此全量模式一定产生空字符串和 FOG_ON 两条记录。

首批纯单元测试

输入预期
SHADER_MACRO(_, FOG_ON)，全量""、"FOG_ON"
(LIT, UNLIT) × (_, FOG)，全量LIT、UNLIT、FOG;LIT、FOG;UNLIT
显式空 Defines必选组取第一项，可空组选空。
{FOG, LIT} 与 {LIT, FOG}同一 CanonicalText，只编译一次。
FOG=1、未知宏、同组多选整个请求失败，无 SLC2。

6. Target 策略与 Slang Session

Target 身份

SOLAR-SHADER-TARGET/v1
platform=windows
backend=vulkan
shaderModel=6_7

TargetKey = LowerHex(SHA-256(UTF8(上面的精确文本)))

TargetKey 只由 Platform、Backend 和 ShaderModel 组成。Slang 版本与固定编译选项进入 CompilerBuildTag，不扩展 TargetKey。

Vulkan 首版映射

  • TargetDesc.format = SLANG_SPIRV；Profile 通过 IGlobalSession::findProfile 从稳定 ShaderModel 字符串映射，未知 profile 直接失败。
  • SPIR-V 版本、Vulkan capability、matrix layout、floating-point、优化和调试配置由 SlangTargetPolicy 的版本化常量设置。
  • SessionDesc.skipSPIRVValidation = false；不能为绕过编译错误而关闭 Slang SPIR-V 验证。
  • 自动 binding 由同一个 linked component 决定；Shader 源不需要 Vulkan set/binding。
  • Target policy 不调用 glslang 转译；代码 blob 直接来自 linked Slang component 的 getEntryPointCode。

Session 创建策略

首版优先正确性：一个 Target × Variant 使用一个 Session，同一 Session 可编译该资源中选中的多个 Program。这样同一宏环境只加载一次 Module，同时不同 Target/Variant 不共享可变状态。

  • 基线发现使用独立空宏 Session。
  • 每个 Variant Session 的 preprocessorMacros 只包含 CanonicalText 中的宏，值统一为 1；SLC2 仍只保存宏名。
  • Session cache 仅存在于当前 Compile 调用，key 为 TargetKey × CanonicalText；请求结束即释放。
  • 将来如需跨请求缓存 Session，必须先单独定义线程安全、文件内容失效与 Slang 对象生命周期，不在首版实现。

Target × Variant Session 分组伪代码

GroupCompilePlan 计划实现 · 请求内复用，不跨请求缓存
输入CompileUnit[]
不变量一个 Session 只有一组 Target/Macros/FileSystem
输出稳定顺序的 SessionGroup[]
GroupCompilePlan(units):
    groups = Map<(TargetKey, VariantText), SessionGroup>()

    FOR unit IN units:
        key = (unit.TargetKey, unit.Variant.CanonicalText)
        groups[key].Units.Add(unit)

    ordered = StableSort(groups.Values,
                         by = TargetTuple then VariantText)
    FOR group IN ordered:
        group.Units = StableSort(group.Units, by = ProgramId)
    return ordered

CreateVariantSession(group):
    defines = group.Variant.Defines.Map(name => (name, "1"))
    return SlangCompilerService.CreateRequestSession(
        group.Target,
        defines,
        SlangShaderFileSystem(request.ResourcePath))

7. 错误、警告与事务终止

CompileMessage 规则

  • 按“请求校验 → Module load → EntryPoint check → link → codegen → IR 构建 → SLC2 自检”的发生顺序追加文本。
  • Slang diagnostics 原文保留文件、行列和 severity；引擎错误使用固定前缀并包含 Resource、Program、Target、Variant 和 Stage 上下文。
  • 多个调用产生相同文本时不做模糊去重，避免删除不同阶段的有效上下文。
  • TreatWarningsAsErrors 只作用于当次实际编译产生的 warning；若触发则状态为 Failed，但保留 warning 文本。
  • CompileMessage 不写入 SLC2，也不在缓存命中时重放。

AppendSlang(blob, context):
    IF blob is null OR blob.Size == 0:
        return
    entries.Add({
        Severity = DetectSeverityWithoutRewritingText(blob),
        Context = context,
        Text = CopyUtf8(blob)
    })

AppendEngineError(context, message):
    entries.Add({ Error, context, message })

FinishFailed(out result):
    result.Status = Failed
    result.CompileMessage = RenderInOccurrenceOrder(entries)
    result.SLC2Data.Clear()

FinishSuccess(bytes, out result):
    ASSERT(NOT HasError)
    result.Status = Success
    result.CompileMessage = RenderInOccurrenceOrder(entries)
    result.SLC2Data = Move(bytes)

内部 entry 仅用于正确聚合；不会扩展公开 ShaderCompileResult，也不会持久化历史 Warning。
