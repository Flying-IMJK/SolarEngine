# 测试与交付

目标：每个阶段形成可验证纵向切片。先证明编译产物正确，再接运行时，最后接 Vulkan。

## 交付闭环

Compile-only 闭环：

```text
Slang 源码
  -> Program/Variant 发现
  -> Target 编译计划
  -> linked component
  -> SPIR-V + ShaderReflectionIR
  -> SLC2
  -> 严格 Reader/Validator
  -> semantic manifest + byte determinism
```

运行时/GPU 闭环：

```text
已存在 SLC2
  -> Program/Target/Variant 选择
  -> runtime reflection
  -> 名称绑定
  -> Vulkan shared PipelineLayout
  -> Descriptor 写入
  -> Dispatch/Draw
```

## 阶段与退出条件

| 阶段 | 内容 | 退出条件 |
| --- | --- | --- |
| P0 前置条件与骨架 | Slang 已由 SolarEngine 接入；请求/结果；API probe | 直接 include Slang 公共头；GlobalSession + smoke；runtime 无 Slang 链接 |
| P1 最小 Compute 编译 | 无资源、无 Variant 单 CS | 无 GPU 通过 Reader/Validator；两次字节一致；SPIR-V 基础校验 |
| P2 Program / Variant | Attribute、Stage、过滤、笛卡尔积、TargetKey | 正负 fixture；空宏 Variant；必选默认项 |
| P3 ReflectionIR + SLC2 | types/blocks/range mapping、Writer/Reader、fingerprint | mutation 捕获 schema invariant；compile-only manifest；runtime 无 Slang |
| P4 Runtime Reflection + Name Binding | 选择、ShaderVar、名称解析、逻辑资源状态 | 无 GPU 解析资源/数组/子块路径；缺失资源阻止提交 |
| P5 Vulkan Compute | Layout、ShaderModule、descriptor、Dispatch | validation layer 无错；缺失资源在 descriptor update 前失败 |
| P6 Vulkan Graphics | VS/PS 联合，HS/DS/GS 可选 | 共享资源合并 binding；Draw 正确 |
| P7 完整已设计能力 | uniform、CB/PB、UAV、数组、counter | 已支持分支均有 GPU 和负向测试 |
| P8 调用点迁移与清理 | 新资产走新入口；旧路径隔离 | 新资产无 Legacy dispatch；旧资产不伪装成功 |

依赖：

```text
P0
 └─ P1
     ├─ P2
     └─ P3
         └─ P4
             └─ P5
                 └─ P6
                     └─ P7
                         └─ P8
```

P0-P3 是编译独立闭环，不依赖运行时 Program、GPU 设备或 Vulkan 资源对象。P5 之后才允许接触 Vulkan。

## API Probe

Probe 必须直接引用 SolarEngine 当前接入 Slang 的真实公共 API，不能提供兼容别名。

覆盖：

- `DeclReflection::getName/getKind/getChildrenCount/getChild/getType`
- 用户 Attribute API
- `findAndCheckEntryPoint`
- component `getLayout/getEntryPointCode/getEntryPointMetadata`
- metadata `isParameterLocationUsed`
- global params type/var layout
- VariableLayout offset/binding space/image format
- TypeLayout kind、size、scalar、matrix、fields、array、resource
- binding range、descriptor range、sub-object range
- explicit counter
- `slang::createGlobalSession`

Semantic smoke 还必须验证：

- ProgramId 精确读取。
- Attribute 内容正确。
- EntryPoint 查找成功。
- logical/descriptor/sub-object 三类 range 语义正确。
- BindingPath 得到预期绝对 set/binding。

新增 Slang API 调用时，同提交扩展 probe。

## Compile Fixture

```text
RunShaderCompileFixture:
  build request from fixture
  ShadersCompilation.Compile(request, result)

  if expected failed:
    require result.Status == Failed
    require result.SLC2Data empty
    require diagnostics contain expected text

  if expected success:
    require result.Status == Success
    artifact = SLC2Reader.ReadAndValidate(result.SLC2Data)
    compare semantic manifest

    compile again
    require second.SLC2Data == result.SLC2Data
```

Manifest 比较 Program/Target/Variant/Stage、IR 和关键 mapping，不把完整 SPIR-V blob 当跨版本永久 golden。

## 编译与 Program 测试

- 固定 Slang API probe。
- 根 Module 直接 Program。
- namespace 内 Program 不发现。
- imported Module Program 不发现。
- ProgramId 重复失败。
- CS 混 graphics 失败。
- Graphics 无 PS 失败。
- 只有 HS 或 DS 失败。
- EntryPoint 无 `[shader]` 可成功。
- EntryPoint uniform/resource 参数失败。

## Variant 测试

- `SHADER_MACRO(_, FOG_ON)` 生成 `""` 和 `"FOG_ON"`。
- 两个 2 项组生成 4 个 Variant。
- 显式空 Defines 执行默认补全。
- 输入宏顺序不同匹配同一 Variant。
- `NAME=VALUE`、未知宏、同组多选失败。
- 声明依赖 Variant 宏才出现时失败。

## Reflection / Cache 测试

- Struct 在两个路径复用：同 typeId，相对 offset 正确累加。
- ConstantBuffer 边界：内部 Uniform 从子块 0 开始。
- ParameterBlock 边界：descriptor 通过 SubElementRegisterSpace 到绝对 set。
- Texture/Buffer/Sampler：Resource Type 的 ranges 非空。
- 资源数组：下标只改变 resourceIndex/dstArrayElement，不改变 binding。
- CB/PB：容器 Type Record 有 count=1 range，具体 block 独立。
- Sub-object：块 range 与 sub-object 一对一。
- StructuredBuffer sub-object 只校验，不生成 SubBlock。
- BindingPath 非法值失败。
- UAV counter owner/auxiliary range 正确。
- 块数组失败。
- 无界数组/range 失败。
- Push Constant 失败。
- 同输入重复编译字节一致。
- mutation 修改 ID/count/hash/fingerprint 时 Reader 失败。

## Vulkan 测试

- Compute 单 Texture：按名称绑定并 Dispatch。
- 资源数组第 N 项：`dstArrayElement` 正确，binding 不变。
- VS/PS 共享资源：一个 binding，stageMask 合并。
- 多 set 与空 set：VkPipelineLayout set 索引与绝对坐标一致。
- 未绑定/null：Draw/Dispatch 前失败，无部分 descriptor update。
- 物理冲突：创建 PipelineLayout 前失败。
- 所有成功场景：validation layer 无 error/warning。

## Golden 与 Mutation

Golden 策略：

- SLC2 schema golden 使用小型手写有效文件。
- SPIR-V 只验证基础结构、hash、非空、同版本确定性。
- Reflection golden 比较稳定 IR 语义。
- SolarEngine 更新内置 Slang 时先做语义 diff，再更新 golden 和 CompilerBuildTag。

Mutation：

- 每次只破坏一个字段。
- 覆盖 magic/major、重复 ProgramId、Target、variant、typeId、blockId、elementCount、rangeIndex、descriptorCount、code hash、fingerprint。
- Reader 必须在精确路径失败。

## 合入门禁

- Build：Windows x64 Editor + Vulkan 编译器模块；Linux x64 至少公共/编译模块。
- Unit：Variant、IR Validator、SLC2、NameResolver、Fingerprint。
- Compile-only：P0-P3 不创建 GPU 也能生成完整 SLC2 并通过 self-read、manifest、mutation、determinism。
- Integration：正负 Slang fixture，失败无部分 SLC2。
- Determinism：同输入连续两次 byte-for-byte 相等。
- GPU：Compute 和 Graphics 通过。
- Validation：Vulkan validation 无 layout/descriptor 问题。
- Dependency audit：runtime 无 Slang；ThirdParty 不含 Slang 工具和 Falcor。
- Legacy audit：新资产调用图无 Parser、RequestCompiler(profile)、AddBindingsForStage 或 SPIR-V 二次反射。

## 完成定义

P0-P8 适用退出条件全部满足时，当前范围完成：

- 新 Slang Shader 资产只调用新 request/result API。
- 旧 HLSL parser 和旧二进制 cache 不在新资产调用链。
- Vulkan Compute/Graphics 使用完整 Program Variant 的共享 Layout。
- 运行时按名称和固定数组下标绑定资源。
- 缺失资源、非法缓存、非法 Variant 和不支持反射结构产生确定性错误。
- Cook/发布、DependencyIndex、默认资源和 runtime lifecycle 优化仍留在后续设计。
